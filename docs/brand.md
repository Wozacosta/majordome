# Brand

**The cloche.** A butler's serving dome on a tray: the majordome brings things to you, and "dome"
is in the name. The round knob on top is a green status light, the always-on daemon (`majord`).

**Wordmark.** Lowercase "majord" at full strength and "ome" at 38% opacity, so the daemon shows
inside the name, with the cloche to its left. Set in DM Sans Regular (SIL OFL) and converted to
paths, so it needs no font.

## Palette

| Name  | Hex       | Use                                  |
| ----- | --------- | ------------------------------------ |
| Ink   | `#14161c` | Cloche on light, production tile     |
| Cream | `#f4efe6` | Cloche on dark, development tile     |
| Live  | `#3ddc84` | The knob, always; never for the dome |

The app's standard theme (`apps/web/src/components/majordome/majordomeTheme.ts`) follows it:
green-tinted ink in dark mode with Live as the accent, white on a pale green-grey in light mode
with a deeper green (`#17804a`) that white text can sit on. Amber and red are kept for warnings
and errors only, which is why the accent is not orange (changed 2026-11-26). The page that makes
a hosted server (`infra/broker/src/startPage.ts`) still has the orange accent.

## Files

In `assets/brand/`:

- `cloche.svg`: the master mark on a 40-unit grid, with the dome highlight. Use it from ~48px up.
- `cloche-small.svg`: the 16px-grid mark (thicker tray, larger knob, no highlight), crisp at
  16 and 32px. `apps/web/src/components/MajordomeCloche.tsx` inlines it for the sidebar.
- `cloche-mono.svg`: everything in `currentColor`, for masks and template icons.
- `wordmark-light.svg` and `wordmark-dark.svg`: for light and dark backgrounds.

App icons are tiles drawn from those masters. Each build channel has its own tile so a dev build
never looks like a release: production is a cream cloche on ink, development an ink cloche on
cream, nightly a cream cloche on a starry indigo. Every tile keeps the green knob. Shapes follow
each platform: a full-bleed opaque square for iOS, `apple-touch-icon` and the web manifest (the
mark stays inside the maskable safe zone), Apple's 824pt body inset 100pt with a shadow for
macOS, and a rounded square for Windows, Linux and favicons. Details (highlight, knob glow, stars)
only appear from 128px.

## Regenerating

Edit the masters, then run `vp run icons:export` (`scripts/export-brand-icons.ts`, rendered with
sharp; no Icon Composer or manual step). It rewrites every icon under `assets/{prod,dev,nightly}`,
`assets/icon.svg` and the development copies in `apps/web/public`. `vp run icons:check` fails when
any of them is stale.

The wordmark is not generated by the script: if the type changes, redraw it and convert the text
to paths.

Not yet redrawn: the mobile app's iOS Icon Composer projects and Android launcher artwork (see
`assets/README.md`), and store or marketing assets.
